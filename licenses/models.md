## Models

Not in the installer: Magi downloads each model the first time its feature is
turned on, from the pinned revision in `models/manifest.toml`. Listed here so
the full set of third-party terms is in one place.

| Feature | Model | Licence |
| --- | --- | --- |
| Search by meaning | [intfloat/multilingual-e5-small](https://huggingface.co/intfloat/multilingual-e5-small) | MIT |
| Text in images (OCR) | [PaddlePaddle/PP-OCRv5_mobile_det](https://huggingface.co/PaddlePaddle/PP-OCRv5_mobile_det_onnx), [latin_PP-OCRv5_mobile_rec](https://huggingface.co/PaddlePaddle/latin_PP-OCRv5_mobile_rec_onnx) | Apache-2.0 |
| Search images by what they show | [google/siglip2-base-patch16-256](https://huggingface.co/google/siglip2-base-patch16-256) (ONNX export: [onnx-community/siglip2-base-patch16-256-ONNX](https://huggingface.co/onnx-community/siglip2-base-patch16-256-ONNX)) | Apache-2.0 |
